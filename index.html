03 / INSTALLATION

Android installation guide

  1. Read the app description, version, source and permissions guidance.
  2. Tap Install / Download. Safety instructions appear before the download starts.
  3. After downloading, open the APK from your Downloads folder.
  4. If Android blocks it, open the settings page it offers for that installer and enable Allow from this source only if you trust the publisher and file.
  5. Return to the installer and continue. Review every permission requested.
  6. Grant only permissions necessary for the app. You can deny optional permissions or revoke them later in Android Settings.
  7. Disable “Allow from this source” again if you no longer need it.

A website cannot grant Android permissions on your behalf. Android controls installation and runtime permissions. Prompts vary by Android version.

Location is optional

Location sharing is off by default. If enabled, the site asks through your browser's permission prompt. If you consent, approximate coordinates may be stored with an analytics event. You can decline and still browse. The site does not silently request GPS access.

APK files are delivered from public GitHub Release assets. Your browser, internet provider, GitHub and hosting provider may process technical connection data under their own policies. This site does not read contacts, messages or private device files.

Retention and contact
